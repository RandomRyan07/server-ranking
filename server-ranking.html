🤖 Discord Bot einrichten

1

Geh zu discord.com/developers/applications → neue App erstellen → Bot → Token kopieren.

2

Bot auf deinen Server einladen mit Read Messages + Read Message History Berechtigung.

3

Kleines Backend (z.B. Node.js) liest Nachrichten aus #result und #hieresult via Discord Bot API und parst Spielernamen + Punkte aus den Nachrichten.

4

Backend stellt z.B. GET /api/ranking?channel=result bereit, das ein JSON-Array mit Spielern zurückgibt.

5

In dieser HTML-Datei DEMO: true auf false setzen und die eigene API-URL bei API_URL eintragen.

🔑 Discord OAuth2 Login

1

App-Seite → OAuth2 → Redirect-URI = URL dieser Seite eintragen.

2

Client-ID kopieren und bei CLIENT_ID im Script eintragen.

3

Scopes: identify + guilds – damit prüfst du ob der Nutzer auf deinem Server ist.
